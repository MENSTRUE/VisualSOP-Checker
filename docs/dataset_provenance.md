# Dataset Provenance

## Primary Dataset

Assembly101

Source:
https://huggingface.co/datasets/cvml-nus/assembly101

Official project:
https://assembly101.github.io/

## Data Used

- 9 original RGB recordings
- 4 additional RGB recordings
- 680 coarse-label annotation files
- 13 video sessions in total

The experimental split uses 62 training,
17 validation and 16 historically exposed
test action intervals.

Annotation timestamps use a 30 FPS timebase,
while the raw recordings use approximately 60 FPS.

## Restrictions

Review original gated access conditions and
CC BY-NC 4.0 terms before using or sharing data.

Raw recordings are excluded from this repository.
