# Project Instructions

Maintain the standard 100 Days of Projects structure.

Do not rename or remove the standard directories.
Do not create a datasets/ directory.
Do not commit source videos, raw datasets,
model checkpoints, feature caches, or secrets.

Use actual execution evidence for all reported metrics.
Never invent training logs, model outputs, or accuracy.

Keep the original Assembly101 source attribution.
Report validation and exploratory test separately.
Do not claim that SOP violations are detected.

Preserve source-group-disjoint evaluation protocols.
Do not use the historically exposed test set for tuning.

Use clear, reproducible scripts and document
environment dependencies and limitations.
